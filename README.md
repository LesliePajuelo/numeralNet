# numeralNet

It takes what you draw on the canvas and it calculates a confidence rating that the drawn number matches a digit between 0-9. It does this after being trained on 60,000 handwritten digits from the <a href="https://en.wikipedia.org/wiki/MNIST_database">MNIST data set</a>.
# Instructions


You can see the images of the digits for the MNIST dataset here. https://github.com/mbornet-hl/MNIST/blob/master/IMAGES/GROUPS/mnist_v5_MNIST-0_01001-02000_25x40.png

In assets/mnist_test.csv there are 10K test images, need to get the remaining 50K for training. 

Will need to get the training data from https://github.com/phoebetronic/mnist



Install node.js version v0.12.7 and npm@1.3.1.
```
npm install
npm start
```
